# TV6 tuần 1 và tuần 2

Thư mục này gom các file liên quan đến Use Case, layout Admin, kế hoạch kiểm thử, Dashboard và quản lý đơn hàng.

- `docs/usecase.png`: sơ đồ Use Case.
- `admin/includes/header.php`, `admin/includes/footer.php`: layout Admin dùng chung.
- `admin/index.php`: Dashboard quản trị.
- `admin/orders.php`: danh sách đơn, tìm kiếm, lọc và phân trang.
- `admin/order_detail.php`: chi tiết đơn hàng.
- `models/Order.php`: truy vấn và xử lý dữ liệu đơn hàng.
- `public/css/style.css`: giao diện và responsive.
- `tests/test_cases.md`: test case của dự án.
- `tests/check_db.php`: kiểm tra cấu trúc và dữ liệu CSDL.

Các file ở đây là bản sao để xem và nộp phần việc. Website chạy theo các file gốc ở thư mục chính của repo.
